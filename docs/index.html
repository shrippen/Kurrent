Kurrent

A KDE Plasma 6 task manager powered by Akonadi & Nextcloud CalDAV. Inbox, Today, Projects, and Labels — right on your desktop.

curl -fsSL https://github.com/shrippen/Kurrent/releases/latest/download/install-linux.sh | sudo bash

sudo is only for distro packages — the widget installs as your user. On non-Arch distros the installer falls back to compiling from source.

Download v0.3 GitHub Roadmap

📥 Inbox → Today flow

Inbox, Today, Tomorrow, Scheduled, Anytime, Recurring, Unlabeled, and Completed views — all from Akonadi.

⚡ Quick Add

tomorrow 18:00 !high #tag @project — natural-language task entry with fuzzy matching.

🗂️ Projects & Labels

Akonadi calendars as projects, CalDAV categories as labels. Color-coded, filterable, drag-and-drop subtasks.

🔁 CalDAV round-trip

Uses your existing Nextcloud / KOrganizer / Merkuro CalDAV setup. No separate login.

🖥️ Panel & Desktop

Works as a panel flyout and a desktop widget. Shared settings, shared config, same full editor.

🌍 Translations

German, Spanish, French, Japanese, Simplified Chinese — with Quick Add understanding your language too.

Prerequisites

  • KDE Plasma 6
  • Akonadi with a task-capable calendar (DAV groupware / Nextcloud VTODO)
  • The installer handles build dependencies on Arch, Fedora, Debian/Ubuntu, and openSUSE

How it works

  • Run the one-liner above — it downloads a prebuilt plugin from the latest GitHub Release into ~/.local
  • Add the Kurrent widget to your panel or desktop
  • Tasks come from your existing Akonadi collections — configure CalDAV in Merkuro or KOrganizer
  • The KDE Store .plasmoid is UI only — the install script adds the Akonadi backend plugin
